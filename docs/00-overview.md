# サウナ ととのい計測アプリ 概要

## 目的

Wear OSスマートウォッチで心拍数を計測し、サウナ入浴中(サウナ→水風呂→休憩)の
自律神経の変化から「ととのい値」を算出・記録するアプリ。「サの国/サウォッチ」を
参考にしつつ、アルゴリズムは独自設計。

## 現在のステータス(2026-08-25時点)

- マルチモジュール構成のスケルトン実装が完了し、3モジュールとも `assembleDebug` に成功。
- 実機/エミュレータでの動作確認、UIの作り込み、アイコン整備は未着手。
- パッケージ名は当初 `com.sanokuni.sauna.*` としていたが、商標(サの国)との混同を避けるため
  `com.totonoi.sauna.*` に変更済み。「ととのい」はサウナ用語として一般的な語であり特定サービス名の
  直接使用ではないと判断しているが、完全にリスクをゼロにしたい場合はさらに一般的な名前
  (例: `com.example.saunalog`)への変更も検討可能。
